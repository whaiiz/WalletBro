# WalletBro

WalletBro is a Next.js TypeScript application for managing expenses and invoices. It supports user registration and authentication (login/register), file uploads, listing and editing expenses and invoices, and viewing statistics and charts.

Key features:
- Authentication (login and register)
- File uploads
- Expense and invoice management
- Visualizations and statistics

Get started by installing dependencies and running the development server using the scripts in `package.json`.
